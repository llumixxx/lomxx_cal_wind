창 드래그 이동 / 최소화 / 층별 탭 지원
🗺 미니맵 + 경로 보기
뿌야 스톤에이지 지도 기반 · 층별 탭 · 흐르는 경로 애니메이션
🎯 사용법
1. 미니맵 열기 누르면 우측 상단에 지도가 뜹니다.
2. 지도 헤더(보라색)를 드래그해서 원하는 위치로 이동할 수 있어요.
3. 1층 / 2층 / 3층 탭으로 각 층 경로를 전환.
4. 분홍색 흐르는 선이 경로를 안내합니다.
5. − 버튼으로 최소화하고 ×로 닫기.
6. 게임 화면 공유: 듀얼모니터 없어도 게임 창을 이 웹 안에서 볼 수 있음.
